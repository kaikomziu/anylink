AnyLink

IDを入れるだけで、PCとAndroidを遠隔操作。

Windowsインストーラー（.exe） Windowsインストール不要版（.exe） Androidアプリ（.apk）

無料 ・ Windows 10/11、Android 8.0 以上 ・ 過去のバージョン

使い方

  1. 操作したい端末と、操作される端末の両方に AnyLink を入れます。
  2. 操作したい側で、相手の画面に出ている9桁のIDを入力して「接続」を押します。
  3. 相手の端末に確認が出ます。相手が操作を許す範囲（マウス・キーボードなど）を選んで「許可」すると、操作できます。

安心して使えるように

  • 接続には毎回、相手の許可が必要です。何ができるかも相手が選べます。
  • 操作されている間は画面に表示が出て、いつでも「切断」できます。
  • 画面と操作は端末どうしで直接（P2P）やり取りし、サーバーには残りません。

知らない人に頼まれてIDを教えたり、接続を許可したりしないでください。

インストールのメモ

  • Windows：「WindowsによってPCが保護されました」と出たら「詳細情報」→「実行」を押します。
  • Android：ダウンロードした apk を開き、「この提供元のアプリを許可」をオンにしてインストールします。 操作を受け入れるには、アプリの案内に従って「ユーザー補助」で AnyLink 遠隔操作 をオンにします（画面を見せるだけなら不要）。
